Command line reference

The canonical binary is named tesseract-crypt. The short alias tscrypt ships alongside it on every platform (Linux, Windows, macOS, BSD) — every command below is identical. On Windows the filename becomes tesseract-crypt.exe.

Synopsis

tesseract-crypt command [options]

With no arguments, brief help is printed and the tool exits with code 0.

Commands

keygen

Generates the key pair NAME.key (private) and NAME.pub (public). Use --passphrase to store the private key locked (Argon2id-encrypted).

OptionDescription
-o NAMEBase filename (required). A trailing .key is ignored if typed.
--passphraseProtect the private key with a passphrase (Argon2id).
--kdf-ops NArgon2id iteration count (opslimit).
--kdf-mem MBArgon2id memory in MiB.

pubkey

Exports the public key from a private key file.

OptionDescription
-k KEYFILEPrivate key file (required).
-o OUTPublic key output file (default: stdout).

encrypt

Encrypts a file or a string. Default input/output: stdin/stdout. Output to a TTY is automatically armored into copy-paste-safe text.

OptionDescription
-r RECIPIENT.pubRecipient public key (public-key mode). Repeat to send to several recipients at once (format v2).
-k SENDER.keySender private key for signing (default: anonymous).
-i INInput file (default: stdin).
-o OUTOutput file (default: stdout).
--armorForce BEGIN/END-labelled text output.
--chunk-size NChunk size (4096 … 16777216; default 65536).
--no-signDisable the sender's signature.
--passphraseSymmetric mode: derive the key from a passphrase (Argon2id).
--text "secret"Encrypt a string (no file); armored output to stdout.

decrypt

Decrypts a message. Armored input is detected automatically. The plaintext is verified (AEAD + signature when requested) before being atomically written to the destination file.

OptionDescription
-k RECIPIENT.keyRecipient private key.
-i INInput file (default: stdin).
-o OUTOutput file (default: stdout).
--require-signer SIGNER.pubRequire a signature from this public key (pinning).
--passphraseSymmetric mode: use a passphrase.
Important. When --require-signer fails the tool exits with code 3 and no output file is written (output is moved into place only after verification succeeds).

sign

Signs a file (detached Ed25519ph streaming signature). Good for release artifacts.

OptionDescription
-k KEYSigner's private key (required).
-i FILEFile to sign.
-o FILE.sigSignature output (default: stdout).

verify

OptionDescription
-k PUBKEYSigner's public key (required).
-i FILEFile (required).
-s FILE.sigSignature (required).

rekey

Re-encrypts an existing message for new recipients/sender (key rotation). Can verify the old required signer and preserve signing. Output is armored to TTY by default when writing to stdout.

OptionDescription
-k OLD_KEYOld recipient private key (or use --old-passphrase for passphrase mode).
--old-passphrase PASSOld passphrase if decrypting symmetric message.
-i INInput message (default: stdin).
-o OUTOutput message (default: stdout).
-r RECIPIENT.pubNew recipient (repeat for multi-recipient).
-s SENDER.keyNew sender private key (optional).
--require-signer SIGNER.pubRequire original signer.
--chunk-size NChunk size (4096 … 16777216).
--no-signDisable signing of new message.

inspect

Reads the message header without decrypting: format version, suite, mode, number of recipients, chunk size, estimated plaintext length, and the signer fingerprint.

OptionDescription
-i FILEMessage (default: stdin). Armored input is detected automatically.
$ tesseract-crypt inspect -i team.enc
format version : 2
mode           : public-key
recipients     : 3
signed         : yes

info

Shows the key type (private/locked/public) and its fingerprint.

OptionDescription
-k KEYFILEKey file (required).

version · help

version prints the version; help prints help. Both are also available as --version / -V and --help / -h.

Exit codes

CodeMeaning
0Success.
1General error (I/O, format, keys).
2Wrong usage (invalid or missing arguments).
3Authentication failure — AEAD, signature, required signer, recipient mismatch, or passphrase mismatch. No output file written on failure.

Examples

# generate a keypair (private key locked with a passphrase)
tesseract-crypt keygen -o alice --passphrase

# encrypt a file for Bob, signed by Alice
tesseract-crypt encrypt -r bob.pub -k alice.key -i secret.txt -o secret.enc

# decrypt + require the signer; failure => exit 3, no file
tesseract-crypt decrypt -k bob.key -i secret.enc -o secret.out \
                        --require-signer alice.pub

# string straight to stdout (auto-armored)
tesseract-crypt encrypt --text "Hello world" -r bob.pub

# passphrase (symmetric) mode
tesseract-crypt encrypt --passphrase -i note.txt -o note.enc

# detached signature + verification
tesseract-crypt sign -k alice.key -i release.tar.gz -o release.tar.gz.sig
tesseract-crypt verify -k alice.pub -i release.tar.gz -s release.tar.gz.sig

# send the same file to a whole team (repeat -r; format v2)
tesseract-crypt encrypt -r alice.pub -r bob.pub -r carol.pub \
                        -k alice.key -i secret.txt -o team.enc

# rekey for Charlie, require original signer Alice
tesseract-crypt rekey -k bob.key -i secret.enc -o secret.rekey -r charlie.pub --require-signer alice.pub

# inspect header & fingerprint
tesseract-crypt inspect -i secret.enc
tesseract-crypt info -k alice.key
