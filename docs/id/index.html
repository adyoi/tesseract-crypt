Beranda Referensi CLI Spesifikasi Format Tentang GitHub EN

Enkripsi string & file
dengan kunci publik/pribadi.

Tesseract adalah perpustakaan C11 + CLI C++17 yang menggabungkan X25519 hybrid encryption, Ed25519 sign-then-encrypt, XChaCha20-Poly1305 per-chunk, dan Argon2id — dirancang untuk Linux, memori konstan, dan verifikasi sebelum tulis.

Mulai cepat Referensi CLI Spesifikasi format

Hybrid public-key

Setiap pesan memakai kunci ephemeral X25519 (forward secrecy) digabung static DH dengan identitas penerima → BLAKE2b KDF → XChaCha20-Poly1305.

Sign-then-encrypt

Tanda tangan Ed25519ph (streaming) disimpan di header yang ikut di-authenticate sebagai AAD. Autentisitas + non-repudiation, terverifikasi sebelum plaintext ditulis.

Streaming chunked

File besar diproses 64 KiB per chunk dengan subkey turunan crypto_kdf. Urutan, truncation, dan splice terdeteksi secara kriptografis.

Mode passphrase

Fallback simetris dengan Argon2id (memory-hard). Parameter dibatasi saat membaca header tak tepercaya untuk mencegah DoS memori.

PEM-like armor

Output ke TTY otomatis dibungkus -----BEGIN TESSERACT MESSAGE----- — aman disalin-tempel.

Atomic output

Dekripsi ditulis ke .part dan hanya di-rename setelah AEAD dan tanda tangan sukses. Data tak-terautentikasi tidak pernah muncul di tujuan.

Mulai cepat

# build
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
ctest --test-dir build --output-on-failure

# pasangan kunci (alias pendek: tscrypt)
tesseract-crypt keygen -o alice
tesseract-crypt keygen -o bob

# enkripsi file untuk Bob, ditandatangani Alice
tesseract-crypt encrypt -r bob.pub -k alice.key -i rahasia.txt -o rahasia.enc

# dekripsi + wajibkan pengirim
tesseract-crypt decrypt -k bob.key -i rahasia.enc -o rahasia.out --require-signer alice.pub

# enkripsi string (langsung ke stdout, otomatis armor)
tesseract-crypt encrypt --text "Halo dunia" -r bob.pub

Contoh library (C)

#include <tesseract/tesseract.h>

tess_key *sec, *pub;
tess_keygen(&sec, &pub);

tess_seal_options so;
tess_seal_options_init(&so);
so.recipient_public = pub;
so.sender_secret    = sec;
so.sign             = 1;

uint8_t *ct;  size_t ct_len;
tess_seal((const uint8_t *)"rahasia", 7, &so, &ct, &ct_len);
