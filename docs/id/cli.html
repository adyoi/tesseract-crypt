Referensi command line

Biner resmi bernama tesseract-crypt. Alias pendek tscrypt ikut ter-install di semua platform (Linux, Windows, macOS, BSD) — semua perintah di bawah identik. Di Windows nama file otomatis menjadi tesseract-crypt.exe.

Sinopsis

tesseract-crypt perintah [opsi]

Tanpa argumen, bantuan singkat dicetak dan keluar dengan kode 0.

Perintah

keygen

Membuat pasangan kunci NAME.key (privat) dan NAME.pub (publik). Gunakan --passphrase untuk menyimpan kunci privat dalam keadaan locked (terenkripsi Argon2id).

OpsiDeskripsi
-o NAMENama berkas dasar (wajib). Akhiran .key diabaikan jika diketik.
--passphraseLindungi kunci privat dengan kata sandi (Argon2id).
--kdf-ops NIterasi Argon2id (opslimit).
--kdf-mem MBMemori Argon2id dalam MiB.

pubkey

Mengekspor kunci publik dari berkas kunci privat.

OpsiDeskripsi
-k KEYFILEBerkas kunci privat (wajib).
-o OUTBerkas output publik (default: stdout).

encrypt

Mengenkripsi berkas atau string. Input/output default: stdin/stdout. Output ke TTY otomatis di-armor menjadi teks aman salin-tempel.

OpsiDeskripsi
-r RECIPIENT.pubKunci publik penerima (mode public-key). Ulangi untuk mengirim ke banyak penerima sekaligus (format v2).
-k SENDER.keyKunci privat pengirim untuk tanda tangan (default: anonim).
-i INBerkas input (default: stdin).
-o OUTBerkas output (default: stdout).
--armorPaksa output teks berlabel BEGIN/END.
--chunk-size NUkuran chunk (4096 … 16777216; default 65536).
--no-signNonaktifkan tanda tangan pengirim.
--passphraseMode simetris: turunkan kunci dari kata sandi (Argon2id).
--text "rahasia"Enkripsi string (tanpa berkas); output ber-armor ke stdout.

decrypt

Mendekripsi pesan. Input ber-armor terdeteksi otomatis. Plaintext diverifikasi (AEAD + tanda tangan bila diminta) sebelum ditulis atomik ke file tujuan.

OpsiDeskripsi
-k RECIPIENT.keyKunci privat penerima.
-i INBerkas input (default: stdin).
-o OUTBerkas output (default: stdout).
--require-signer SIGNER.pubWajibkan tanda tangan dari kunci publik ini (pinning).
--passphraseMode simetris: gunakan kata sandi.
Penting. Saat --require-signer gagal, berakhir dengan kode keluar 3 dan tidak ada berkas output yang ditulis (output hanya dipindahkan setelah verifikasi sukses).

sign

Menandatangani berkas (tanda tangan detached, Ed25519ph streaming). Cocok untuk artefak rilis.

OpsiDeskripsi
-k KEYKunci privat penanda tangan (wajib).
-i FILEBerkas yang ditandatangani.
-o FILE.sigOutput tanda tangan (default: stdout).

verify

OpsiDeskripsi
-k PUBKEYKunci publik penanda tangan (wajib).
-i FILEBerkas (wajib).
-s FILE.sigTanda tangan (wajib).

inspect

Membaca header pesan tanpa mendekripsi: versi format, suite, mode, jumlah penerima, ukuran chunk, perkiraan panjang plaintext, dan fingerprint penanda tangan.

OpsiDeskripsi
-i FILEPesan (default: stdin). Ber-armor otomatis dideteksi.
$ tesseract-crypt inspect -i tim.enc
format version : 2
mode           : public-key
recipients     : 3
signed         : yes

info

Menampilkan tipe kunci (privat/terkunci/publik) dan fingerprint-nya.

OpsiDeskripsi
-k KEYFILEBerkas kunci (wajib).

version · help

version mencetak versi; help mencetak bantuan. Keduanya juga tersedia sebagai --version / -V dan --help / -h.

Kode keluar

KodeMakna
0Sukses.
1Kesalahan umum (I/O, format, kunci).
2Penggunaan salah (argumen tidak valid / tidak lengkap).
3Otentikasi gagal — AEAD, tanda tangan, kata sandi salah, atau pesan tidak ditujukan untuk kunci ini.

Contoh

# buat pasangan kunci (privat terkunci kata sandi)
tesseract-crypt keygen -o alice --passphrase

# enkripsi berkas untuk Bob, ditandatangani Alice
tesseract-crypt encrypt -r bob.pub -k alice.key -i rahasia.txt -o rahasia.enc

# dekripsi + wajibkan penanda tangan; gagal => exit 3, tanpa file
tesseract-crypt decrypt -k bob.key -i rahasia.enc -o rahasia.out \
                        --require-signer alice.pub

# string langsung ke stdout (otomatis ber-armor)
tesseract-crypt encrypt --text "Halo dunia" -r bob.pub

# mode simetris kata sandi
tesseract-crypt encrypt --passphrase -i catatan.txt -o catatan.enc

# tanda tangan detached + verifikasi
tesseract-crypt sign -k alice.key -i rilis.tar.gz -o rilis.tar.gz.sig
tesseract-crypt verify -k alice.pub -i rilis.tar.gz -s rilis.tar.gz.sig

# kirim berkas yang sama ke satu tim (ulangi -r; format v2)
tesseract-crypt encrypt -r alice.pub -r bob.pub -r carol.pub \
                        -k alice.key -i rahasia.txt -o tim.enc

# inspeksi header & fingerprint
tesseract-crypt inspect -i rahasia.enc
tesseract-crypt info -k alice.key
