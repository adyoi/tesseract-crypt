Encrypt strings & files
with public/private keys.

Tesseract is a C11 library + C++17 CLI combining X25519 hybrid encryption, Ed25519 sign-then-encrypt, XChaCha20-Poly1305 per-chunk, and Argon2id — built for Linux, constant memory, and verify-before-write.

Quick start CLI reference Format spec

Hybrid public-key

Every message uses an ephemeral X25519 key (forward secrecy) combined with a static DH against the recipient's identity → BLAKE2b KDF → XChaCha20-Poly1305.

Sign-then-encrypt

The Ed25519ph (streaming) signature lives in the header, which is authenticated as AAD. Authenticity + non-repudiation, verified before any plaintext is written.

Streaming chunked

Large files are processed 64 KiB per chunk with subkeys derived via crypto_kdf. Reordering, truncation, and splices are detected cryptographically.

Passphrase mode

Symmetric fallback with Argon2id (memory-hard). Parameters are capped while reading untrusted headers to prevent memory DoS.

PEM-like armor

TTY output is automatically wrapped in -----BEGIN TESSERACT MESSAGE----- — safe to copy-paste. inspect detects armored input automatically.

Atomic output

Decryption is written to .part and renamed only after the AEAD and signature succeed. Unauthenticated data never reaches the destination.

Multi-recipient (v2)

One message for a whole team: a random data key wrapped once per recipient under their own X25519 DH secret. Repeat -r on the CLI; non-recipients are rejected explicitly (exit code 3).

Quick start

# build
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
ctest --test-dir build --output-on-failure

# keypair (short alias: tscrypt)
tesseract-crypt keygen -o alice
tesseract-crypt keygen -o bob

# encrypt file for Bob, signed by Alice
tesseract-crypt encrypt -r bob.pub -k alice.key -i secret.txt -o secret.enc

# decrypt + require the sender
tesseract-crypt decrypt -k bob.key -i secret.enc -o secret.out --require-signer alice.pub

# rekey for new recipients (key rotation)
tesseract-crypt keygen -o charlie
tesseract-crypt rekey -k bob.key -i secret.enc -o secret.rekey -r charlie.pub --require-signer alice.pub

# encrypt a string (straight to stdout, auto-armored)
tesseract-crypt encrypt --text "Hello world" -r bob.pub

Library example (C)

#include <tesseract/tesseract.h>

tess_key *sec, *pub;
tess_keygen(&sec, &pub);

tess_seal_options so;
tess_seal_options_init(&so);
so.recipient_public = pub;
so.sender_secret    = sec;
so.sign             = 1;

uint8_t *ct;  size_t ct_len;
tess_seal((const uint8_t *)"secret", 6, &so, &ct, &ct_len);
